# MATLAB SAR Oil Spill Detection

## Requirements
- MATLAB R2020b or later
- Image Processing Toolbox
- Statistics and Machine Learning Toolbox

## Sample Data
Download sample SAR images from: [link]
Or use synthetic data generator: synthetic_sar_data.m

## Quick Start
1. Open MATLAB
2. Set working directory to repository root
3. Run: Main()
4. Results saved to: output/
